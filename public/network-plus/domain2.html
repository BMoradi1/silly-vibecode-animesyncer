2.1 Routing Concepts

Routing is the process of selecting a path across one or more networks for traffic to travel from a source to a destination. Routers operate at Layer 3 (Network) of the OSI model and make forwarding decisions based on destination IP addresses.

Default Gateway

The default gateway is the router interface that serves as the exit point for a subnet. When a host needs to communicate with a device on a different network, it forwards the packet to its default gateway. Without a properly configured default gateway, a host can only communicate with devices on its own local subnet.

Exam Note The default gateway must be on the same subnet as the host. A misconfigured default gateway is one of the most common causes of connectivity problems to remote networks.

Routing Tables

Every router maintains a routing table — a data structure that lists known network destinations and the best path (next-hop address or exit interface) to reach each one. Routing table entries are populated by:

  • Directly connected networks — automatically added when interfaces are configured and brought up
  • Static routes — manually configured by an administrator
  • Dynamic routing protocols — learned automatically from neighboring routers

When a packet arrives, the router performs a longest prefix match lookup. If multiple routes match, the most specific route (longest subnet mask) wins. If no match is found, the packet is forwarded via the default route (0.0.0.0/0) or dropped if none exists.

Routing Table Example ===================================================== Destination Subnet Mask Next Hop Type ----------------------------------------------------- 10.1.1.0 255.255.255.0 -- Connected 10.2.2.0 255.255.255.0 10.1.1.2 Static 192.168.0.0 255.255.0.0 10.1.1.3 OSPF 0.0.0.0 0.0.0.0 10.1.1.1 Default =====================================================

Static vs. Dynamic Routing

Static routing requires an administrator to manually add, modify, and remove routes. It works well for small, predictable networks but does not adapt to topology changes automatically.

Dynamic routing uses routing protocols so routers exchange information and automatically update their tables when the network changes. It is essential for large, complex, or frequently changing environments.

Distance-Vector vs. Link-State Protocols

Dynamic routing protocols fall into two major categories:

  • Distance-vector — Routers share their entire routing table with directly connected neighbors at regular intervals. They choose paths based on a metric such as hop count. Examples: RIP, EIGRP (hybrid/advanced distance-vector). Susceptible to routing loops; mitigations include split horizon, route poisoning, and hold-down timers.
  • Link-state — Routers build a complete map (topology database) of the network by flooding link-state advertisements (LSAs). Each router independently calculates the shortest path using Dijkstra's SPF algorithm. Example: OSPF. Converges faster, but uses more memory and CPU.

Path-Vector Protocol

BGP (Border Gateway Protocol) is classified as a path-vector protocol. It is the routing protocol of the Internet, exchanging reachability information between autonomous systems (AS). BGP makes routing decisions based on path attributes, policies, and network policies rather than a simple metric.

What is the maximum hop count for RIP?
15 hops. A destination 16 hops away is considered unreachable. This limits RIP to small network deployments.
What algorithm does OSPF use?
Dijkstra's Shortest Path First (SPF) algorithm. Each OSPF router builds a topology map and independently calculates the best path to every destination.
What is the difference between IGP and EGP?
An Interior Gateway Protocol (IGP) routes within a single autonomous system (e.g., OSPF, EIGRP, RIP). An Exterior Gateway Protocol (EGP) routes between autonomous systems (e.g., BGP).

2.2 Switching & VLANs

Switching operates at Layer 2 (Data Link) of the OSI model. Switches use MAC addresses to forward frames within a local network, providing dedicated bandwidth to each port and creating separate collision domains.

MAC Address Table

A switch maintains a MAC address table (also called a CAM table) that maps MAC addresses to switch ports. When a frame arrives:

  1. Learning — The switch records the source MAC address and the port it arrived on.
  2. Forwarding — If the destination MAC is in the table, the frame is sent out the associated port.
  3. Flooding — If the destination MAC is unknown (not in the table), the frame is sent out all ports except the one it arrived on.
  4. Filtering — If the source and destination are on the same port, the frame is dropped (filtered).

Spanning Tree Protocol (STP / 802.1D)

When switches are connected in redundant topologies, Layer 2 loops can form, causing broadcast storms, MAC table instability, and duplicate frames. STP prevents this by logically blocking redundant paths.

  • Root Bridge — The switch with the lowest Bridge ID (priority + MAC) becomes the root. All traffic flows toward it.
  • Root Port — Each non-root switch selects one port with the lowest cost path to the root bridge.
  • Designated Port — One port per segment that forwards traffic toward the root bridge.
  • Blocked Port — Redundant ports that are disabled to prevent loops but can activate if a failure occurs.

STP Port States: Blocking → Listening → Learning → Forwarding (convergence can take 30–50 seconds).

Rapid Spanning Tree Protocol (RSTP / 802.1w)

RSTP dramatically improves convergence time (often under 6 seconds) by introducing new port roles and states:

  • Alternate Port — Backup to the root port (replaces STP's blocked state for root port failure)
  • Backup Port — Backup to the designated port on the same segment
  • Port states simplified to: Discarding, Learning, Forwarding
Exam Warning Know the difference between STP (802.1D) and RSTP (802.1w). The exam tests on port states and convergence time. STP takes 30-50 seconds; RSTP converges in seconds.

VLANs (Virtual Local Area Networks)

A VLAN is a logical segmentation of a physical switch into multiple broadcast domains. Devices on different VLANs cannot communicate without a Layer 3 device (router or Layer 3 switch).

  • Reduces broadcast traffic by limiting the broadcast domain
  • Improves security by isolating sensitive traffic
  • Simplifies network management (group by function, not location)
  • VLAN 1 is the default VLAN on most switches (avoid using it in production)

802.1Q Tagging

IEEE 802.1Q is the standard for VLAN tagging. It inserts a 4-byte tag into the Ethernet frame header that includes the VLAN ID (12 bits, supporting VLANs 1–4094). The native VLAN is the VLAN whose traffic travels across a trunk port untagged. Both ends of a trunk must agree on the native VLAN to avoid VLAN mismatches.

Inter-VLAN Routing

Since VLANs are separate broadcast domains, a Layer 3 device is needed for communication between them:

  • Router-on-a-stick — A single router interface with sub-interfaces, each assigned to a VLAN. The router's physical port connects to the switch via a trunk link.
  • Layer 3 switch (SVI) — A managed switch that can route between VLANs using Switch Virtual Interfaces. Faster and more common in enterprise environments.

Port Mirroring / SPAN

SPAN (Switched Port Analyzer) copies traffic from one or more source ports (or VLANs) to a destination port for monitoring. This allows a network analyzer or IDS to inspect traffic without being inline. RSPAN extends this capability across switches.

Power over Ethernet (PoE)

PoE delivers electrical power over Ethernet cabling, eliminating the need for separate power supplies for devices like IP phones, wireless access points, and security cameras.

What is the native VLAN?
The native VLAN is the VLAN whose traffic crosses a trunk link untagged. By default it is VLAN 1. Both sides of a trunk must match on the native VLAN setting to avoid a mismatch.
What problem does STP solve?
STP (Spanning Tree Protocol, 802.1D) prevents Layer 2 switching loops by logically blocking redundant paths. Without STP, broadcast storms, MAC table instability, and duplicate frames would occur.

2.3 Wireless Networking

Wireless networking uses radio frequency (RF) signals to transmit data over the air, governed by the IEEE 802.11 family of standards. Understanding wireless standards, frequencies, security, and deployment considerations is essential for the Network+ exam.

Frequency Bands

2.4 GHz Band

  • 11 channels in North America (1–11), only 3 non-overlapping channels: 1, 6, 11
  • Better range and wall penetration
  • More interference from microwaves, Bluetooth, cordless phones, and neighboring networks

5 GHz Band

  • 24 non-overlapping channels (using 20 MHz channels)
  • Higher throughput, less interference
  • Shorter range, less wall penetration
  • Some channels require DFS (Dynamic Frequency Selection) to avoid radar

6 GHz Band (Wi-Fi 6E / Wi-Fi 7)

  • 59 additional 20 MHz channels (or 7 super-wide 160 MHz channels)
  • Extremely low congestion (new spectrum, no legacy devices)
  • Shortest range of the three bands
Exam Note For the 2.4 GHz band, always plan your wireless deployment using channels 1, 6, and 11 to avoid co-channel interference. Adjacent APs should never be on the same or overlapping channels.

Channel Bonding

Channel bonding combines adjacent channels to increase bandwidth. 802.11n supports 40 MHz (2 channels), 802.11ac supports up to 160 MHz (8 channels), and 802.11be supports up to 320 MHz. Wider channels provide more throughput but increase the chance of interference, especially in the crowded 2.4 GHz band where bonding is generally not recommended.

Wireless Architecture

  • SSID (Service Set Identifier) — The human-readable name of a wireless network
  • BSS (Basic Service Set) — A single access point and its associated clients (identified by BSSID, which is the AP's MAC address)
  • ESS (Extended Service Set) — Multiple APs sharing the same SSID to provide seamless roaming across a larger area
  • IBSS (Independent BSS) — Ad-hoc mode where devices communicate directly without an AP

Wireless Security

ProtocolEncryptionAuthenticationStatus
WEPRC4 (64/128-bit)Open / Shared KeyDeprecated — easily cracked
WPATKIP (RC4-based)PSK or 802.1XLegacy — not recommended
WPA2AES-CCMPPSK or 802.1X (Enterprise)Current standard, widely deployed

WPA2-Personal uses a Pre-Shared Key (PSK). WPA2-Enterprise uses 802.1X with a RADIUS server for individual credentials. WPA3 introduces SAE (Simultaneous Authentication of Equals), which replaces the 4-way handshake with a more secure key exchange resistant to offline dictionary attacks.

Security Alert WEP is fundamentally broken and must never be used. WPA with TKIP is also deprecated. Always deploy WPA2 (AES) at minimum, or WPA3 when supported by all devices.

Wireless Controllers

In enterprise environments, a Wireless LAN Controller (WLC) centrally manages multiple access points (called "lightweight APs" or LWAPs). Benefits include:

  • Centralized configuration, firmware management, and policy enforcement
  • Automatic RF channel and power management
  • Seamless roaming between APs
  • Rogue AP detection

Lightweight APs use CAPWAP (Control and Provisioning of Wireless Access Points) to communicate with the controller.

Site Surveys & Heat Maps

A wireless site survey is performed before and after deploying a wireless network to optimize coverage and performance:

  • Predictive survey — Uses software to model RF behavior based on floor plans and building materials
  • Active survey — A technician walks through the area with a survey tool, measuring signal strength, noise, and throughput
  • Passive survey — Listens to RF signals without associating with any AP

Results are visualized as heat maps, showing signal strength (RSSI) using color gradients. They help identify dead zones, areas of co-channel interference, and optimal AP placement.

What are the three non-overlapping channels in 2.4 GHz?
Channels 1, 6, and 11. These channels do not overlap each other's frequency range and should be used to minimize interference between adjacent access points.
What is the difference between WPA2-Personal and WPA2-Enterprise?
WPA2-Personal uses a shared Pre-Shared Key (PSK) for all users. WPA2-Enterprise uses 802.1X authentication with a RADIUS server, providing unique credentials per user and stronger security.

2.4 WAN Technologies

A Wide Area Network (WAN) connects geographically dispersed LANs, often spanning cities, countries, or continents. WANs are typically provided by service providers (ISPs, telcos) and use a variety of technologies depending on bandwidth, cost, and availability requirements.

Point-to-Point vs. Multipoint

  • Point-to-Point — A dedicated link between two locations (e.g., a leased line or T1). Simple, predictable, but expensive for many locations.
  • Multipoint (Point-to-Multipoint) — One central site connects to multiple remote sites (e.g., hub-and-spoke MPLS, Frame Relay). More cost-effective for connecting many branches.

WAN Technology Overview

DSL (Digital Subscriber Line)

  • Uses existing copper telephone lines
  • ADSL: Asymmetric — faster download than upload (typical home service)
  • SDSL/VDSL: Symmetric or very high-speed variants
  • Speed degrades with distance from the DSLAM (Central Office)
  • Max range approximately 18,000 feet (5.5 km)

Cable (DOCSIS)

  • Uses coaxial cable (shared HFC — Hybrid Fiber-Coaxial) infrastructure
  • DOCSIS 3.0: up to ~1 Gbps downstream; DOCSIS 3.1: up to 10 Gbps
  • Shared bandwidth among neighbors (speeds can vary during peak hours)

Fiber Optic (SONET/SDH)

  • SONET (Synchronous Optical Networking) — North American standard
  • SDH (Synchronous Digital Hierarchy) — International equivalent
  • Provides high-speed, reliable, long-distance transport
  • Uses ring topologies with automatic failover for redundancy
  • FTTH/FTTP (Fiber to the Home/Premises) delivers fiber directly to end users

Satellite

  • Available almost anywhere with a clear view of the sky
  • Traditional GEO satellites: high latency (500–700 ms round-trip)
  • LEO constellations (e.g., Starlink): lower latency (20–50 ms), higher speeds
  • Affected by weather (rain fade) and line-of-sight obstructions

Cellular (4G LTE / 5G)

  • 4G LTE: 10–50 Mbps typical, up to 300+ Mbps
  • 5G: Sub-6 GHz (100–900 Mbps), mmWave (1–10+ Gbps, very short range)
  • Used for mobile connectivity, WAN failover, and fixed wireless access
  • Considerations: data caps, coverage area, signal strength

MPLS (Multiprotocol Label Switching)

  • Operates between Layer 2 and Layer 3 (sometimes called "Layer 2.5")
  • Uses labels instead of IP addresses for fast packet forwarding
  • Provides QoS, traffic engineering, and VPN services
  • Commonly used for enterprise WAN connecting multiple sites with guaranteed performance
  • More expensive than Internet-based VPNs but more reliable and predictable

Metro Ethernet

  • Extends Ethernet technology across a metropolitan area
  • Speeds from 10 Mbps to 100 Gbps
  • Simple to configure (familiar Ethernet interfaces)
  • Cost-effective alternative to MPLS for metro-area connectivity

Leased Lines (T1/T3, E1/E3)

SD-WAN (Software-Defined WAN)

SD-WAN is a modern approach to WAN connectivity that abstracts the underlying transport (MPLS, broadband, LTE, etc.) and uses software to intelligently route traffic across multiple links based on application requirements.

  • Transport-agnostic — Can use any combination of MPLS, broadband, cellular, etc.
  • Centralized management — Policies configured from a single controller/dashboard
  • Application-aware routing — Steers traffic based on application type, latency, jitter, and packet loss
  • Cost savings — Supplements or replaces expensive MPLS with cheaper broadband
  • Built-in encryption — Typically uses IPsec tunnels for security
Exam Tip SD-WAN is a heavily tested topic on the N10-009. Know that it provides centralized management, uses multiple transport types simultaneously, and makes application-aware routing decisions.
What is the speed of a T1 line?
1.544 Mbps. A T1 consists of 24 DS0 channels, each running at 64 Kbps (24 x 64 Kbps = 1.536 Mbps + 8 Kbps framing = 1.544 Mbps).
What layer does MPLS operate at?
MPLS operates between Layer 2 and Layer 3, often called "Layer 2.5." It uses labels to make forwarding decisions rather than examining the full IP header at each hop.

2.5 Cabling & Connectors

Understanding cable types, connectors, standards, and their appropriate use is a core competency for Network+ and for real-world network implementation. The right cable for the job depends on speed requirements, distance, environment, and budget.

Copper Cabling — Twisted Pair

Twisted-pair cabling is the most common type of network cable. Wires are twisted together in pairs to reduce electromagnetic interference (EMI). UTP (Unshielded Twisted Pair) is standard; STP (Shielded Twisted Pair) adds a foil or braided shield for environments with high interference.

Coaxial Cable

  • RG-6 — Used for cable TV and cable Internet (DOCSIS). 75-ohm impedance.
  • RG-59 — Thinner, shorter-distance; used in older CCTV installations. 75-ohm.
  • Connectors: F-type (threaded, most common for cable), BNC (bayonet, used in legacy networking and some test equipment)
  • Provides good shielding against EMI due to its construction (center conductor, dielectric, shield, jacket)

Fiber Optic Cabling

Fiber uses pulses of light to transmit data through a glass or plastic core. It is immune to EMI, supports very long distances, and provides the highest bandwidth.

Single-Mode Fiber (SMF)

  • Very small core diameter: 8–10 microns
  • Uses a laser light source
  • Supports distances up to 80+ km (with amplification, hundreds of km)
  • More expensive (laser transceivers)
  • Color code: Yellow jacket

Multimode Fiber (MMF)

  • Larger core diameter: 50 or 62.5 microns
  • Uses LED or VCSEL light source
  • Shorter distances (up to 550 m for 10G, depending on grade)
  • Less expensive than single-mode
  • Color codes: Orange (OM1/OM2) or Aqua (OM3/OM4) or Lime Green (OM5)

Straight-Through vs. Crossover Cables

  • Straight-through — Same pinout on both ends (e.g., T568B to T568B). Connects unlike devices: PC to switch, switch to router.
  • Crossover — Different pinout on each end (T568A on one, T568B on the other). Connects like devices: switch to switch, PC to PC.
  • Rollover (console) — Pins reversed end-to-end. Used to connect a PC serial port to a router/switch console port (RJ-45 to DB-9).
Exam Note Modern switches and NICs support Auto-MDI-X, which automatically detects and adjusts for straight-through or crossover connections. However, the exam still tests on when each cable type is traditionally required.

Plenum vs. PVC Jacket

  • Plenum-rated cable — Uses fire-retardant, low-smoke jacket materials. Required in plenum spaces (air-handling areas above drop ceilings or below raised floors). More expensive.
  • PVC (non-plenum) — Standard jacket. Used in regular wall runs, conduits, and areas that are not used for air circulation. Releases toxic fumes when burned.
  • Riser-rated cable — Designed for vertical runs between floors. More fire-resistant than PVC but less than plenum.

Cable Management Best Practices

  • Use patch panels to organize and terminate horizontal cable runs
  • Label all cables and ports with a consistent naming scheme
  • Use cable trays, ladder racks, and velcro straps (not zip ties, which can damage cables)
  • Maintain proper bend radius — do not kink or sharply bend cables
  • Separate data cables from power cables to reduce EMI (maintain at least 12 inches)
  • Document all cable runs in a structured cabling diagram
What is the maximum distance for Cat 6a at 10 Gbps?
100 meters (328 feet). Cat 6a supports 10GBASE-T at the full 100-meter distance, unlike Cat 6 which is limited to 55 meters for 10G.
Which fiber connector is most common in modern data centers?
The LC (Lucent Connector). It is a small form-factor connector that fits into SFP and SFP+ transceivers, making it the standard for modern data center and enterprise deployments.
What color jacket identifies single-mode fiber?
Yellow. Multimode fiber jackets are orange (OM1/OM2), aqua (OM3/OM4), or lime green (OM5).

Routers

Routers operate at Layer 3 and forward packets between different IP networks. They examine the destination IP address, consult their routing table, and forward the packet toward the next hop. Key functions include:

  • Connecting LANs to WANs (e.g., your office to the Internet)
  • Segmenting broadcast domains (each router interface is a separate broadcast domain)
  • Implementing NAT (Network Address Translation) to share a public IP
  • Running routing protocols (OSPF, EIGRP, BGP) for dynamic path selection
  • Applying ACLs (Access Control Lists) for basic traffic filtering

Layer 2 vs. Layer 3 Switches

  • Layer 2 switch — Forwards frames based on MAC addresses only. All ports in the same VLAN are in the same broadcast domain. Requires an external router for inter-VLAN routing.
  • Layer 3 switch — Can route packets between VLANs using SVIs (Switch Virtual Interfaces) or routed ports. Combines switching speed with routing capability. Standard in enterprise campus networks.

Firewalls

Firewalls control traffic flow based on security rules. They can operate at multiple OSI layers:

  • Packet filtering (Layer 3/4) — Filters by IP address, port, protocol
  • Stateful inspection (Layer 3/4) — Tracks connection state; allows return traffic for established sessions
  • Application-layer / NGFW (Layer 7) — Inspects application data (HTTP, DNS, etc.), deep packet inspection, malware detection
Exam Warning Do not confuse a firewall with an IDS/IPS. A firewall enforces rules you define (allow/deny). An IDS detects suspicious activity and alerts. An IPS detects and actively blocks threats. They serve complementary but different purposes.

Wireless Access Points (APs)

Access points bridge wireless clients to the wired network. They operate at Layer 1 (radio signals) and Layer 2 (MAC-based frame forwarding). In enterprise environments, APs are often "lightweight" and managed by a wireless controller (WLC).

Load Balancers

Load balancers distribute incoming traffic across a pool of backend servers to ensure no single server is overwhelmed. They improve availability, reliability, and response time.

  • Layer 4 load balancing — Distributes based on IP address and TCP/UDP port
  • Layer 7 load balancing — Distributes based on application content (URL, HTTP headers, cookies)
  • Common algorithms: Round Robin, Least Connections, IP Hash, Weighted

Proxy Servers

A proxy server acts as an intermediary between clients and the Internet:

  • Forward proxy — Sits between internal clients and the Internet. Provides caching, content filtering, and anonymity.
  • Reverse proxy — Sits in front of servers. Provides load balancing, SSL offloading, and protection from direct access.
  • Transparent proxy — Intercepts traffic without client configuration. Used for content filtering in schools and enterprises.

IDS and IPS

  • IDS (Intrusion Detection System) — Monitors traffic passively and generates alerts when suspicious activity is detected. Does not block traffic. Typically connected via a SPAN/mirror port.
  • IPS (Intrusion Prevention System) — Sits inline (in the traffic path) and can actively block or drop malicious traffic in real time.
  • Detection methods: Signature-based (matches known patterns), Anomaly-based (detects deviations from baseline), Heuristic (uses rules and AI)

VPN Concentrators

A VPN concentrator is a dedicated device that handles a large number of simultaneous VPN tunnels. It manages encryption, decryption, authentication, and tunnel establishment for remote-access or site-to-site VPN connections. Common protocols: IPsec, SSL/TLS VPN.

Other Devices

  • Modem — Converts digital data to analog signals (and vice versa) for transmission over telephone lines (DSL), coaxial cable, or other analog media. Operates at Layer 1.
  • Media Converter — Converts signals between different physical media (e.g., copper to single-mode fiber, multimode to single-mode). Operates at Layer 1. Does not change the data.
  • Hub — A Layer 1 multiport repeater. Receives a signal on one port and retransmits it to all other ports. Creates a single collision domain. Obsolete in modern networks.
  • Repeater — Regenerates and amplifies a weakened signal to extend cable distance. Layer 1 device.
Exam Tip When a question asks "which device" to solve a problem, match the requirement to the OSI layer. Need MAC-based forwarding? Layer 2 switch. Need to route between subnets? Router or Layer 3 switch. Need to filter application traffic? Firewall or proxy. Need to detect intrusions? IDS/IPS.
What is the key difference between an IDS and an IPS?
An IDS (Intrusion Detection System) passively monitors and alerts on suspicious activity but does not block traffic. An IPS (Intrusion Prevention System) sits inline and can actively block or drop malicious traffic in real time.
At what OSI layer does a hub operate?
Layer 1 (Physical). A hub is a multiport repeater that simply regenerates electrical signals to all ports. It does not examine MAC addresses or make forwarding decisions.
What distinguishes a Layer 3 switch from a Layer 2 switch?
A Layer 3 switch can route packets between VLANs (and different subnets) using Switch Virtual Interfaces (SVIs) or routed ports, combining switching and routing in one device. A Layer 2 switch only forwards frames based on MAC addresses within a single broadcast domain.

Domain 2 Quiz — Network Implementation

Test your knowledge with 10 questions covering routing, switching, wireless, WAN, cabling, and network devices.

1. Which routing protocol uses the Dijkstra SPF algorithm and has an administrative distance of 110?

  • A. RIPv2
  • B. EIGRP
  • C. OSPF
  • D. BGP
OSPF (Open Shortest Path First) is a link-state routing protocol that uses Dijkstra's Shortest Path First algorithm. Its default administrative distance is 110. RIP uses Bellman-Ford (AD 120), EIGRP uses DUAL (AD 90), and BGP uses best-path selection (AD 20 for eBGP).

2. A network administrator needs to carry traffic for VLANs 10, 20, and 30 between two switches. What type of port should be configured on the link between them?

  • A. Access port
  • B. Trunk port
  • C. SPAN port
  • D. PoE port
A trunk port carries traffic for multiple VLANs between switches using 802.1Q tagging. An access port belongs to only one VLAN and is used for end devices. A SPAN port mirrors traffic for monitoring, and PoE delivers power over Ethernet.

3. Which 802.11 standard introduced OFDMA, BSS coloring, and Target Wake Time (TWT), and operates on 2.4 GHz, 5 GHz, and 6 GHz bands?

  • A. 802.11n (Wi-Fi 4)
  • B. 802.11ac (Wi-Fi 5)
  • C. 802.11be (Wi-Fi 7)
  • D. 802.11ax (Wi-Fi 6)
802.11ax (Wi-Fi 6 / Wi-Fi 6E) introduced OFDMA for efficient multi-user access, BSS coloring to reduce co-channel interference, and Target Wake Time (TWT) for power savings. Wi-Fi 6E extends operation into the 6 GHz band.

4. What is the speed of a T1 leased line?

  • A. 1.544 Mbps
  • B. 2.048 Mbps
  • C. 44.736 Mbps
  • D. 10 Mbps
A T1 line runs at 1.544 Mbps and consists of 24 DS0 channels at 64 Kbps each. 2.048 Mbps is the speed of an E1 (European standard). 44.736 Mbps is a T3 line.

5. Which copper cable category supports 10 Gbps Ethernet at the full 100-meter distance?

  • A. Cat 5e
  • B. Cat 6
  • C. Cat 6a
  • D. Cat 8
Cat 6a supports 10GBASE-T at the full 100-meter distance at 500 MHz. Cat 6 supports 10 Gbps only up to 55 meters. Cat 5e maxes out at 1 Gbps. Cat 8 supports 25/40 Gbps but only to 30 meters.

6. A network device sits inline with traffic and actively blocks malicious packets in real time. What type of device is this?

  • A. IDS (Intrusion Detection System)
  • B. IPS (Intrusion Prevention System)
  • C. Proxy server
  • D. Load balancer
An IPS (Intrusion Prevention System) sits inline and actively blocks or drops malicious traffic. An IDS only passively monitors and alerts; it does not sit inline or block traffic. A proxy acts as an intermediary, and a load balancer distributes traffic.

7. Which protocol prevents Layer 2 switching loops by logically blocking redundant paths?

  • A. 802.1Q
  • B. 802.11ac
  • C. ARP
  • D. STP (802.1D)
STP (Spanning Tree Protocol, IEEE 802.1D) prevents Layer 2 loops by electing a root bridge and blocking redundant paths. 802.1Q is the VLAN tagging standard. 802.11ac is a wireless standard. ARP resolves IP addresses to MAC addresses.

8. An organization wants to use multiple WAN transports (MPLS, broadband, LTE) with centralized management and application-aware routing. Which technology should they deploy?

  • A. SD-WAN
  • B. MPLS alone
  • C. SONET
  • D. DSL bonding
SD-WAN (Software-Defined WAN) is transport-agnostic and can use MPLS, broadband, and cellular simultaneously. It provides centralized management and makes application-aware routing decisions to optimize traffic across all available links.

9. Which fiber connector is a small form-factor design commonly used with SFP/SFP+ transceivers in modern data centers?

  • A. ST
  • B. SC
  • C. LC
  • D. MTRJ
The LC (Lucent Connector) is a small form-factor fiber connector that is the standard for SFP and SFP+ transceivers used in modern data centers. ST uses a bayonet twist-lock (legacy). SC is a larger push-pull connector. MTRJ is a compact duplex connector.

10. Which three non-overlapping channels should be used when deploying 2.4 GHz wireless access points to minimize interference?

  • A. 1, 5, 10
  • B. 1, 6, 11
  • C. 2, 7, 12
  • D. 3, 8, 13
Channels 1, 6, and 11 are the three non-overlapping channels in the 2.4 GHz band (in North America with channels 1-11). Using these channels prevents co-channel interference between adjacent access points.
