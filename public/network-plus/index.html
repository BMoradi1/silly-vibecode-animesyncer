Exam Objectives at a Glance

The N10-009 replaced the N10-008 and reflects current networking technologies including expanded cloud, virtualization, and automation topics.

  • Domain 1 (23%) — Networking Concepts: OSI layers, protocols, ports, IP addressing, subnetting, cloud/virtualization
  • Domain 2 (19%) — Network Implementation: Routing, switching, wireless standards, WAN technologies, cabling
  • Domain 3 (16%) — Network Operations: Monitoring, documentation, high availability, disaster recovery, policies
  • Domain 4 (19%) — Network Security: Security concepts, attack types, mitigation, hardening, remote access, physical security
  • Domain 5 (23%) — Network Troubleshooting: Methodology, tools, cable/connectivity issues, performance problems
